# Online Keyboard Tester

Welcome to Online Keyboard Tester, a free tool that helps users check whether their keyboard keys are working correctly.

## Features

- Test all alphabet keys (A–Z).
- Check number and special character keys.
- Test Space, Enter, Shift, Ctrl, and Alt keys.
- Identify keys that may not be responding.
- Check keyboard functionality in real time.
- No software installation required.

## How to Use

1. Visit our online keyboard testing tool.
2. Press any key on your keyboard.
3. Check whether the pressed key is highlighted.
4. Repeat the process to test other keys.
