Como testar?

Clique nesta página e pressione uma tecla de cada vez. Se a tecla correspondente ficar azul, o navegador recebeu o sinal dessa tecla. Use “Limpar teste” para começar novamente.

Observação

Este teste verifica se o navegador detecta o pressionamento da tecla. Ele não consegue confirmar sozinho se há defeitos físicos, problemas de conexão ou falhas que ocorram fora do navegador.
